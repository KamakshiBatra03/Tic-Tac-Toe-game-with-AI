# 🕹️ Tic Tac Toe (AI Edition)

A modern, responsive **Tic Tac Toe** game featuring a clean UI and an intelligent AI opponent. This project challenges players against a rule-based algorithm designed to provide a consistent and challenging experience.

---

## 🌟 Features

* **Intelligent AI:** Moves are determined by a specialized algorithm to ensure the AI plays optimally.
* **Winner Validation:** Real-time detection of win conditions with a visual "Congo" announcement.
* **Responsive Design:** Beautifully crafted with a teal-themed interface and soft shadows.
* **Dynamic States:** Smooth transition between active gameplay and the "New Game" reset state.

---

| Component | Technology |

| **Logic** | JavaScript (ES6+) |
